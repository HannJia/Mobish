# 墨笔生花 mobish 1.1.5

发布日期为 2026-11-24（北京时间）。本版新增独立的「拆书」，灵感对话可以按目录查阅知识库原文，并改进知识库、审校、典籍和写作台的多处功能；模型请求支持三种接口格式。

## 灵感对话与知识库

- 勾选参考知识库后，可以点名资料或小节，也可以询问多份资料之间的关系。回复下方会列出引用，点击即可核对原文；追问时可以接着读上一节或下一节。
- 配置 BGE-M3 等向量模型后，灵感对话还能补查措辞不同的相关段落；向量服务暂时不可用时，继续按目录和关键词查询。
- 创建知识库后直接进入详情页，可以马上导入资料或手动添加。
- 知识条目可以添加和筛选标签、按指定顺序合并，也可以设为“仅作者可见”，或“写到指定章节后才供 AI 使用”。
- 从资料中提取的人物候选，核对引文后可以写入典籍。

## 拆书

- 左侧栏新增「拆书」：可以导入参考书、选用已有资料，或拆自己的章节；空书架也能使用。
- 分析范围可选选段、单章、开篇三章、全卷或全书。长任务会保存逐段进度，到达预算后可以追加预算继续。
- 经过编辑和确认的成果，可以用于灵感对话、知识库、章纲、写作台和典籍。

## 创作

- 灵感建书可以直接进入讨论，也可以先把一句想法整理成创作设定；书名和故事起点由作者确认并可修改。
- 对话中出现值得保存的资料时，会显示橙色提示。
- 混选故事方案后，可以检查方案之间的冲突，并记录作者的取舍。
- 审校中心可以并排核对上一章章尾和下一章章首的原句。
- 典籍能区分角色“亲自到场”和“被提及”。
- 写作台可以从作者选中的段落提炼写法规则，试写后再决定是否用于本书。

## 模型

- 写作、对话等请求支持 Chat Completions、Responses 和 Anthropic Messages 三种接口格式，可以在模型设置中选择，也可以通过连接测试自动判断。已有模型默认仍使用 Chat Completions；接口地址为 Anthropic 官方（`api.anthropic.com`）时自动使用 Anthropic Messages。
- 自动重试设有请求次数上限。

## 已知问题

- 拆书、灵感对话引用等功能的真实模型效果，以及硅基流动、MiniMax、混元、OpenRouter、Ollama、LM Studio 和各联网搜索路径，尚未用真实密钥逐一实测。
- Responses 与 Anthropic Messages 两种接口格式只经过自动化模拟测试。如果某个服务商用这两种格式出错，可以在模型设置中改回 Chat Completions。
- 用 1.1.5 设置过“AI 可见范围”或合并过的知识条目，以及含试写写法规则的作品，导出的项目备份不能在 1.1.4 及更早版本中导入。
- 安装包尚未进行代码签名，Windows 可能显示未知发布者提示；发布页提供 SHA-256 校验文件。

## 安装

安装包为 `mobish-1.1.5.exe`，面向 Windows x64。1.0.10 及以后的版本可在软件内检查更新，也可手动下载安装；数据位置不变，更新前建议先备份项目。
