# 墨笔生花 mobish 1.1.9

发布日期为 2026-11-28（北京时间）。本版新增首次使用引导，整理典籍与人物资料的分工，打磨写作台与创建流程的布局和可读性，并让长篇作品在创建流程中不再卡住界面。

## 新手引导与入口

- **首次使用引导**：书架新增「新手启程」清单，按「先自己写」或「先配置 AI 模型」两条路线带路；写作台、结构、典籍、知识库、拆书等页面在关键按钮旁显示可关闭的提示点。老用户自动跳过。
- **「关于」页**：新增官方网站、在线使用说明和 QQ 交流群入口。
- **模型配置**：常用服务商旁新增「获取密钥」快捷入口。

## 典籍与人物资料

- **典籍页「相关资料」**：人物资料、数据面板、知识库三个入口从页面最底部移到页头，带图标和一句说明。从典籍跳过去后，页面顶部显示「← 返回典籍 · 人物资料」，点返回回到原来的典籍视图。返回按钮按来源显示「返回写作 / 返回典籍 / 返回结构」等，不再一律写「返回写作」。
- **分工更清楚**：典籍负责按章节回看（「人物」页签改名为「人物状态」，底部可展开全部状态变化与原文证据）；人物资料页只负责编辑人物设定，关系图和人物详情固定显示最新一章，并提供「按章节回看关系与知情 → 典籍」。人物编辑页标题统一为「人物资料」，知识库页标题与面包屑统一为「知识库」。

## 写作台

- **章节目录**：默认只展开当前章所在的卷并定位到当前章；切到别的卷时自动展开那一卷，离开时收起没有手动展开过的卷。
- **窄窗口**：800–1120 像素宽时，右侧案头改为占一列并自动收起左侧目录，不再盖住正文；540 像素宽时稿纸不再被挤出窗口，底栏不再与「已保存」重叠。
- **页边批注**：页边汇总文字可以点击，正文会跳到屏幕外的批注或候选；屏幕外还有批注时，页边栏上下边缘显示「↑ 上方还有 N 项」「↓ 下方还有 N 项」。
- **手机阅读宽度预览**：正文排版中可一键切换 390 像素手机宽度预览。

## 创建流程与规划

- **故事骨架页**：空白状态改为三张入口卡（AI 生成候选、手写一个方案、粘贴已有大纲），修复原来的元素重叠；生成时每个方案生成完就先显示出来，不再等三个方案全部完成。
- **场景规划**：生成时每个场景生成完就先显示为卡片。
- **长篇作品更流畅**：创建流程每次保存都要为每一章重算审校信息。现在这部分计算提速约一倍，并分批进行，64 章的作品界面最长卡顿从十几秒降到约 0.4 秒；没有改动任何审校输入时不再重复计算。
- **结构页**：章节树不再重复显示「第 N 章」。

## 界面与可读性

- 次要文字和辅助数字的颜色加深，宣纸、青瓷、夜墨三个主题的正文对比度达到常用标准；夜墨主题的红色按钮和审校矩阵色块改用更深的实心色。
- 侧栏导航、零散小字统一调大到 12 像素，说明类文字调到 13 像素。
- 按钮、链接、折叠箭头、章号链接等点击区域不小于 24 像素。

## 稳定性与问题修复

- **自动更新国内备用源**：GitHub 检查或下载失败时，自动改从官网国内源 `dl.mobish.cn` 获取同版本安装包，并同样校验文件完整性。
- 备份、导入、恢复或云同步正在进行时切换页面会被拦下，现在会提示原因，不再像是点了没反应；没有这些操作时不会出现提示。
- 书架「移入回收站」确认后立即关闭弹窗，保存失败时自动恢复并提示。
- 拆书结果带入灵感对话时，出处不再显示原始 Markdown，改为可点击的「回看出处」。
- 关闭没有改动的窗口时跳过多余的保存与同步。

## 验证

- 全量自动化测试、性能测试、更新下载校验冒烟、`vue-tsc` 类型检查、Windows x64 打包构建、打包版启动冒烟与发布包审计。
- 开发版浏览器中用 64 章合成作品，在 1440、860、540 三种宽度下检查各主要页面的裁切与溢出，并在三个主题下检查文字对比度。

## 已知问题

- 64 章以上的长篇作品，打开创建流程页仍需等待十几秒（界面不再卡住）。
- 拆书与云同步仍标注「暂未开发」，未纳入本版回归范围。
- 安装包尚未进行代码签名，Windows 可能显示未知发布者提示；发布页提供 SHA-256 校验文件。

## 安装

安装包为 `mobish-1.1.9.exe`，面向 Windows x64。1.0.10 及以后的版本可在软件内检查更新，也可手动下载安装；数据位置不变，更新前建议先备份项目。
