# 墨笔生花 mobish 1.1.6

发布日期为 2026-11-24（北京时间）。本版改进灵感对话的布局和窗口关闭流程，并修复引用资料文字重叠的问题。

## 灵感对话

- 新建作品页的创建步骤移到左侧，标题和四种起点上移，给对话区留出更多高度。
- 对话区左侧用短横线按顺序标出每轮提问：悬停显示该轮消息的简短预览，点击跳回原消息。原来的「本轮问题」卡片已移除。
- 右侧设定面板可独立滚动，设定较多时不再把聊天区挤短；「整理设定」和「完成」并排放在面板底部，面板可以收起，对话区随之变宽。
- 引用资料的长标题和多层章节路径按内容换行，相邻条目不再重叠；展开后来源列表显示在下方，「查看草稿」留在引用按钮旁边。
- 把对话内容存入知识库后，提示改为「保存成功」，正文写明知识库名和条目名。旧会话里的旧提示仍能识别。

## 关闭窗口

- 灵感对话里只有输入框草稿时，点窗口右上角「×」会直接退出，草稿保存在「历史会话」中，重开后可恢复。
- 创建页有未保存的输入，或设置页有未保存的模型配置时，点「×」会先询问；选「继续编辑」后窗口和输入保持原样，之后可再次关闭。

## 验证

- 在 Windows 桌面开发版上用真实模型走完以上改动：关闭窗口（直接退出与确认两种情形）、草稿恢复、三处引用的长标题换行（含最小窗口宽度）、「查看草稿」位置（有引用与无引用）、保存回执、短横线预览与跳转、设定面板收起。
- 同一次验证中，带知识库的灵感对话在 Chat Completions、Responses 和 Anthropic Messages 三种接口格式下都得到了正常回复；拆书在真实模型上完成了 3 章和长篇（60 章合成文本）的分析，到达预算时会自动停下，可追加预算继续。

## 已知问题

- Responses 和 Anthropic Messages 只在一个中转服务上用真实密钥测试过，没有直连官方端点测试；Responses 的流式写作也未实测。如果某个服务商用这两种格式出错，可以在模型设置中改回 Chat Completions。
- 长篇拆书没有跑满全书（只验证了预算上限和续跑入口），逐章质量没有逐一核对。
- 硅基流动、MiniMax、混元、OpenRouter、Ollama、LM Studio 和各联网搜索路径，尚未用真实密钥逐一实测。
- 用 1.1.5 设置过「AI 可见范围」或合并过的知识条目，以及含试写写法规则的作品，导出的项目备份不能在 1.1.4 及更早版本中导入。
- 「测试搜索」的超时和停止按钮尚未实现。
- 安装包尚未进行代码签名，Windows 可能显示未知发布者提示；发布页提供 SHA-256 校验文件。

## 安装

安装包为 `mobish-1.1.6.exe`，面向 Windows x64。1.0.10 及以后的版本可在软件内检查更新，也可手动下载安装；数据位置不变，更新前建议先备份项目。
