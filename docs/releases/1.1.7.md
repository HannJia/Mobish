# 墨笔生花 mobish 1.1.7

发布日期为 2026-11-25（北京时间）。本版补上灵感对话历史会话的删除，让联网搜索的测试可以停止，并在设置中加入「云同步」入口（暂未开发，尚未开放）。

## 灵感对话

- 历史会话可以逐条确认删除。删除当前会话后进入空白会话，取消删除不会丢失会话和草稿，重启后删除结果保持。
- 旧会话不再因为超过五条被自动移除，历史按最近更新排序。

## 联网搜索

- 独立搜索服务的「测试搜索」旁新增「停止测试」。停止后会断开正在进行的请求，可以立即重新测试；停止后才返回的结果会被忽略；30 秒没有响应会提示超时。

## 云同步（暂未开发）

- 设置、左侧栏和底栏出现「云同步」入口，并标注「暂未开发」：这项功能尚未向用户开放，注册需要邀请码，目前不能使用。项目历史与单作品恢复标注「可使用」，本地历史和恢复不受影响。
- 云同步正式开放的时间另行通知。需要在其他电脑继续写作时，请继续使用书架上的「备份项目」导出，再到另一台电脑导入。

## 验证

- 全量测试、性能测试、更新下载测试、构建、打包版冒烟和发布审计均通过；135 个界面状态检查与创建流程冒烟通过。
- Windows 桌面上用真实模型验证：历史会话删除（取消、确认、重启后保持）、联网搜索「停止测试」（含底层请求被断开）、三种主题下窄窗口的联网搜索布局、知识库检索（未配向量、启用 BGE-M3、向量服务不通三种情形回答一致）、拆书的预算停点和续跑、拆书成果的联动去向。
- 1.1.6 升级到 1.1.7、卸载和重装均已在 Windows 上验证，用户数据保持不变。

## 已知问题

- 拆书结果带入灵感对话时，出处行显示的是未渲染的原始文字（`[回看出处](#/breakdown/…)`），不能点击跳回原文。
- 拆书时模型响应较慢时可能出现「请求超时（120 秒）」，已完成的结果会保留，点击「继续分析」即可从中断处重试。
- 知识库检索三种情形在测试问题上结果一致，未能拉开差距，向量检索的收益还缺少更难的对照数据。
- 服务商、本机模型和各联网搜索路径（硅基流动、MiniMax、混元、OpenRouter、Ollama、LM Studio 等）尚未用真实密钥逐一实测。
- 用 1.1.5 及以后版本设置过「AI 可见范围」或合并过的知识条目，以及含试写写法规则的作品，导出的项目备份不能在 1.1.4 及更早版本中导入。
- 安装包尚未进行代码签名，Windows 可能显示未知发布者提示；发布页提供 SHA-256 校验文件。

## 安装

安装包为 `mobish-1.1.7.exe`，面向 Windows x64。1.0.10 及以后的版本可在软件内检查更新，也可手动下载安装；数据位置不变，更新前建议先备份项目。
