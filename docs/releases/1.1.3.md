# 墨笔生花 mobish 1.1.3

发布日期为 2026-11-22（北京时间）。本版改进联网搜索和灵感对话，新增多家服务商与本机模型、伏笔提醒、DOCX 导出，创建作品时可以先选知识库。

## 模型与服务商

- **更多服务商**：常用服务商新增硅基流动、MiniMax、腾讯混元、OpenRouter，并新增“本机”分组：Ollama、LM Studio。本机模型不需要 API 密钥，密钥可以留空。
- **向量模型推荐 bge-m3**：向量模型的常用服务商把硅基流动放在第一位（`BAAI/bge-m3` 目前免费），选中后自动填好模型名，只需填自己的密钥；附注册链接（作者的邀请链接，注册双方可能获得赠送额度，以硅基流动活动规则为准；也可以直接到官网注册）。
- **获取模型时只列向量模型**：添加向量模型时，“获取模型”只列出向量模型（不含重排序模型），推荐的模型排在前面并高亮，需付费的 `Pro/` 模型会标出；可勾选“显示全部模型”。
- **参数不支持时自动重试**：部分模型不接受 temperature、top_p 等参数，会直接报错。现在遇到这类报错会去掉该参数自动重发（最多三次）；要求改用 `max_completion_tokens` 的模型会自动改名。密钥、额度、内容审核等错误不会重试。

## 联网搜索

- Firecrawl 不再作为默认搜索服务，并注明需要境外网络；连不上时会提示原因。默认服务改为博查，需要在“设置 → 联网搜索”填写密钥。
- 通义、智谱、豆包模型可以直接用自带的搜索；设置页写明了这一点，并说明智谱的密钥可以共用。
- 搜索服务 30 秒内没有响应会结束等待并提示，不再一直显示“搜索中…”。
- 设置页的输入框对齐；模型自带搜索出错时改用搜索服务的开关说明更清楚。

## 灵感对话与创建作品

- **创建时先选知识库**：创建作品的入口新增“参考知识库”，灵感对话和这部作品共用同一份选择，作品创建后自动挂载。
- 联网开关挪到发送区、背景信息窗口旁边。
- “对话选项 · 历史与参考资料”改成带箭头的展开条，看得出可以点开。
- “一并保存当前灵感讨论”的勾选框和文字放在同一行；“继续讨论”按钮更醒目，并显示已有讨论的条数。

## 写作与规划

- **伏笔提醒**：计划回收章节已经写过却还没回收的伏笔标为“超期”，埋设或最近一次推进后 30 章没有动静的标为“久未推进”。提醒显示在规划页的伏笔追踪上方，写作台底部状态栏显示数量，点击可以跳到规划页。
- **导出 Word 文档（.docx）**：作品导出新增真正的 .docx 格式（含总纲或仅正文），每章另起一页、章节标题使用“标题 1”样式，可在 Word 的导航窗格中跳转。原有的 Word 兼容 .doc 仍然保留。

## 知识库

- 正文中的 Markdown 表格会显示为表格。
- 启用向量检索时，知识库按标题小节建立索引，每段带上所属小节的标题，检索能命中具体小节。

## 其他

- “关于”页新增“在 GitHub 点 Star”入口，并显示当前 Star 数（每天最多获取一次，获取失败时不显示）。
- 用满 7 天、写了 10 章以上时，书架会出现一次提示，邀请到 GitHub 点个 Star；点“去看看”或“不再提示”后不再出现。
- 左侧栏新增“打赏”入口，可以用微信或支付宝打赏支持作者。打赏不影响任何功能；想出现在致谢名单里，可以在付款备注里写上称呼。
- 安装时选择其他位置，会安装到所选位置下的 mobish 文件夹。

## 已知问题

- 各厂商的联网搜索（除 Firecrawl 外）以及新增服务商、本机模型尚未用真实密钥逐一实测。
- 以前按旧规则被切成多段的知识库条目不会自动合并，可以删除后重新“整份导入”。
- 安装包尚未进行代码签名，Windows 可能显示未知发布者提示；发布页提供 SHA-256 校验文件。

## 安装

安装包为 `mobish-1.1.3.exe`，面向 Windows x64。1.0.10 及以后的版本可在软件内检查更新，也可手动下载安装；数据位置不变，更新前建议先备份项目。
