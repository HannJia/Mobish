# 墨笔生花 mobish 1.1.4

发布日期为 2026-11-23（北京时间）。本版是一组小改进：模型测试失败时说清原因、书名推荐、问题反馈诊断信息，以及几处界面细节。

## 模型设置

- **测试失败时说清原因**：“测试”失败后不再只贴服务商返回的原文，而是先说明问题出在哪、该怎么办：
  - 401：密钥无效或填错；
  - 403：没有调用权限。报错里提到“分组”时，会直接点明是中转站的分组问题（分组被停用、模型不在分组里，或分组只允许指定客户端使用）；
  - 404：接口地址或模型名不对；
  - 429：额度用完或请求太频繁；
  - 400 / 422：参数不被接受；
  - 5xx、超时、网络错误：服务商或网络问题。

  服务商的原始返回收在下方，可以展开查看。遇到 403 时还会提醒：能获取模型列表只说明地址和密钥能连上，不代表有调用权限。
- Ollama、LM Studio 等本机模型不填密钥也能点“测试”。

## 创建作品

- **AI 推荐书名**：在“作品契约”里编辑作品名称时，可以点“AI 推荐书名”。AI 根据已填的设定一次给出 5 个风格不同的书名，每个附一句取名思路；点一下就能填入，也可以“换一批”，或者直接手动输入自己的书名。

## 灵感对话

- 标题右侧显示当前挂载的知识库（没有时显示“未挂载知识库”），点开就能勾选或取消。和创建入口的“参考知识库”是同一份选择。
- 发送区的“背景信息窗口”圆环一直显示，没有消息时为灰色，发第一条消息时不会再把旁边的按钮挤开。接近上限时仍会自动压缩较早的对话。

## 其他

- 快速连续切换主题时只保留一条“主题：××”提示，不再叠出一长串；屏幕上已有的相同提示也不会重复弹出。
- “关于”页新增“复制诊断信息”和“保存诊断包（.json）”，反馈问题时可以附上。诊断信息包含版本、系统、作品和知识库数量、模型配置概况，不含作品内容、知识库内容、文件路径、API 密钥和接口地址。

## 已知问题

- 各厂商的联网搜索（除 Firecrawl 外）以及硅基流动、MiniMax、混元、OpenRouter、本机模型尚未用真实密钥逐一实测。
- 安装包尚未进行代码签名，Windows 可能显示未知发布者提示；发布页提供 SHA-256 校验文件。

## 安装

安装包为 `mobish-1.1.4.exe`，面向 Windows x64。1.0.10 及以后的版本可在软件内检查更新，也可手动下载安装；数据位置不变，更新前建议先备份项目。
