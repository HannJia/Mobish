# 墨笔生花 mobish 1.1.1

发布日期为 2026-11-21（北京时间）。

本版主要改进模型配置和联网搜索。

## 添加模型

- 添加模型时可以选择厂商预设：DeepSeek、通义千问（阿里云百炼）、Kimi（月之暗面）、智谱 GLM、豆包（火山方舟）、OpenAI、Claude（Anthropic）、Gemini（Google）。预设只填写官方接口地址，模型名称通过“获取模型”选择或自行填写。
- 接口地址已带版本号（如 `/v3`、`/v1beta`）或以 `/openai` 结尾时，不再额外补上 `/v1`。

## 联网搜索

- 对话的搜索方式新增“通义千问联网搜索”“智谱网络搜索”“Gemini Google 搜索”，豆包（火山方舟）通过 Responses 接口搜索。选“自动”时按官方接口地址识别。
- 新增独立搜索服务（设置 → 联网搜索），支持 Firecrawl、博查、智谱搜索 API、Tavily 和自建 SearXNG：先搜索，再把带编号的结果交给模型回答。默认使用无需密钥的 Firecrawl 免费搜索，开箱即可联网。
- DeepSeek、Kimi 和 Gemini 在自动模式下按官方地址或模型名称识别；经中转站调用时也改用独立搜索服务（Gemini 走官方地址时仍用 Google 搜索）。
- 出错时自动改用（默认开启）：模型内置搜索出错或没有搜到时，改用独立搜索服务；所选搜索服务未填密钥、额度用完或出错时，改用 Firecrawl 免费搜索。发生改用时会弹出一次提示，联网测试的结果里也会说明。
- 独立搜索服务的 API 密钥只保存在本机：桌面版加密保存，浏览器版只在当前会话内有效。
- 桌面版的搜索请求由主进程发送，只允许访问上述服务的固定接口，以及 SearXNG 的 JSON 搜索地址。

## 设置与写作技能

- 设置导航去掉“任务分配”，它仍在“模型配置”页内；“联网搜索”改为单独一页。
- 任务分配的每项任务下面列出推荐的模型类型和模型系列例子，供选择时参考。
- 添加模型时用两个并排按钮选择“写作／对话”或“向量模型”；选向量模型后提供通义、智谱、硅基流动、OpenAI 的接口地址预设。已添加的模型不能更改类型。
- 设置页排版：常用服务商按国内、海外分行；表单字段标题加大加深；技能编辑、关于页小节标题不再比页面标题大；“高级设置”等折叠标题加粗。
- 模型卡片上的类型改为文字说明，标签只列实际会用到这个模型的任务（包括未分配时的默认模型和跟随大纲的对话），没用到的模型显示“未分配任务”。
- “测试对话”和“测试联网”合并为一个“测试”：先测对话再测联网，分两行显示结果；对话不通时不再测联网，并标明是对话出错。
- 修复向量模型接口地址以版本号结尾（如智谱 /api/paas/v4）时被多拼一段 /v1 的问题。
- 优化五个内置写作技能的规则：避免在正文里写出“目标”“阻力”等结构，审校只报告有证据的冲突，分析时不把人物的谎言和传闻当作事实。你没改过的内置技能会自动换成新规则，改过的保持不变；也可以在技能编辑里点“恢复内置规则”。

## 软件更新与安装

- 软件更新窗口改为按窗口宽度排版：较窄时上下排列，版本号不再折行；下载进度显示百分比和已下载大小。
- 更新内容按标题、段落和列表显示，不再直接露出 `##`、`-` 等 Markdown 符号。从 1.1.0 及更早版本更新时，旧版窗口仍按原样显示本版说明。
- 安装程序的窗口标题和提示，以及系统“应用和功能”中的名称改用“墨笔生花”。程序文件名和安装目录仍为 mobish，覆盖升级不受影响。

## 兼容性

- 新的搜索方式只记录在本机；模型配置和对话记录写入的字段与 1.1.0 保持一致。

## 已知限制

- 除 Firecrawl 免费搜索外，发布前没有用真实 API 密钥请求过各厂商和搜索服务，测试使用的是按官方文档构造的模拟响应。通义千问搜索结果的返回位置、豆包 Responses 网页搜索，以及各搜索服务的实际返回字段尚待实测。
- Firecrawl 免费搜索按网络地址每日限量，官方未公布具体次数；从中国大陆能否直接访问尚未验证。联网对话时，搜索词会发送到 Firecrawl（美国）。Firecrawl 服务条款对第三方应用内使用免密钥接口没有明确说明。
- 安装包尚未进行代码签名。

## 安装

安装包为 `mobish-1.1.1.exe`，面向 Windows x64。1.0.10、1.0.11 和 1.1.0 用户可在软件内检查更新，也可手动下载安装；数据位置不变，更新前建议先备份项目。安装包尚未进行代码签名，Windows 可能显示未知发布者提示；发布页提供 SHA-256 校验文件。
