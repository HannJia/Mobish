# 墨笔生花 mobish 1.1.0

发布日期为 2026-11-19（北京时间）。这是“朱批”V3 工作台的正式版：界面全部改用 V3 原生控件，旧版界面和组件库已经移除。

## 界面

- 设置、数据面板、创建向导、知识库、云同步、章节任务、分卷规划、知识导入和方向编辑器全部改用 V3 原生控件；提示和确认框统一样式，只有最上层的对话框响应 Tab 与 Esc。
- 夜墨主题下，单选框、复选框、下拉框、滚动条等系统控件跟随深色显示。
- 书架、人物、大纲、分卷、章节和知识库的空状态换成水墨插图，在夜墨主题下自动适配。
- 写作台案头标签按使用时机重新排列为“顾问 · 对话 · 记忆 · 候选 · 审校”，默认打开顾问；开始审校时仍自动切到审校。
- 写作台：编辑后批注仍保留，各标签页都显示页边批注，支持多份修订候选；审校中心和书架可直接跳到对应章节。
- 左侧导航显示待处理标记，命令面板增加常用操作，Alt+T 切换主题；审校中心的批量审校可以中途停止，典籍关系图按实际宽度绘制。

## 说明文字

- 去掉直接露给用户的开发术语，如“落盘”“快照”“基线”“投影”“Canon”“请求账本”等。
- 用词统一：“审校”“API 密钥”“Token”；对你说话时用“你”。
- 精简各面板反复出现的“不代表……”“不会自动……”“仅供参考”类说明，只在首次使用引导里讲一次“只有你采纳的内容才会进入正文和故事典籍”。
- 约定：AI 生成的叫“候选”，你未保存的修改叫“草稿”，你保存的叫“作者版本”。例如自动写作产出的是“自动候选稿”。

## 错误提示

- 数据异常时，界面显示一句能看懂的话，例如“备份数据校验未通过，文件可能不完整或已损坏。”原始错误保留在“复制诊断信息”按钮里，复制后包含版本号、时间和原始错误，便于反馈。
- 报错中不再出现“V3”字样，例如旧版本的云端数据会提示“来自不支持的旧版本”。

## 安装与数据

安装包为 `mobish-1.1.0.exe`，面向 Windows x64，包含桌面运行环境、字体及本地 OCR 资源，无需另装 Node.js。

1.0.10 和 1.0.11 用户可在软件内检查更新，也可手动下载安装。1.0.9 及更早客户端使用旧安装包命名规则，请手动下载。数据位置与 1.0.11 相同，作品、设置和云同步账号保持不变；更新前建议先备份项目。

AI 功能需要自行配置模型服务及额度。云同步多设备冲突已在同一台电脑上用两个独立客户端验证（本地服务端的双客户端测试和此前的线上服务测试），两台实体设备的验证尚未进行。

安装包尚未进行代码签名，Windows 可能显示未知发布者提示；发布页提供 SHA-256 校验文件。
