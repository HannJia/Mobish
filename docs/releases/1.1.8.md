# 墨笔生花 mobish 1.1.8

发布日期为 2026-11-27（北京时间）。本版重构作品契约、故事骨架与分卷大纲三套创作流程界面，全面升级写作台案头与选区交互，修复多处真实大模型长文本与规划缺陷，并为 Windows 进程补齐「墨笔生花」名称与印章图标。

## 创作流程与规划

- **作品契约重构**：扩展为 9 张契约卡片（结局方向独立成卡），支持逐卡修订历史与恢复、目标字数按万字显示、起点名称独立保存并带入灵感开篇年代；探索对话支持继承并检索挂载知识库，并修复 `explanation` 字段被误拦截的问题。
- **故事骨架与分卷大纲重构**：分卷总纲改为流式渐进生成并去重保存版本历史；修复总纲启发式分卷解析将「第一卷前六章细纲」「卷一末：…」等非分卷行误拆成 0 章假分卷的问题；修复挂载知识库后无法批量确认章纲的规划版本校验错误。
- **开书首批入典与提醒**：开书准备页新增双列「首批入典」勾选预览，开书即可将核心人物与世界设定写入典籍；进入下一章写作时若上一章仍有未确认入典变化，顶部提供醒目提醒与直达入口。
- **新建作品隔离**：通过灵感对话成功建书后，再次新建作品不再自动载入已成书的旧会话与旧书名/知识库（旧讨论仍保留在「历史会话」下拉中可随时重开）；点击「新建会话」时同步清空共享知识库选择。

## 写作台与知识库

- **案头与导航升级**：将写作顾问「接下来怎么写（两方向构思）」合并进书内对话，聊天页统一使用印章 LOGO 头像；新增独立「角色」案头页并支持显式绑定角色数据面板；从角色面板跳转「典籍 / 人物资料 / 数据面板」后支持顶部一键「← 返回写作」。
- **工具栏与选区体验**：顶部将定稿检查、全章审校与完成本章归组到写作模式左侧，底栏「正文排版」按钮加框提示可点击；生成选区修订候选后，若锚点在可视区外自动滚回可视区并重排页边浮签（保留当前右侧标签不打断），窄屏隐藏页边时自动切至「候选」标签。
- **结构化知识归档**：书内对话与灵感对话存入知识库时，自动按作品名或「待命名」归档为带目录层级的文档（建书后「待命名」自动更名为书名）并附带「保存成功」回执。

## 真实模型稳定性与桌面细节

- **长文本与思考模型适配**：非流式请求默认超时由 120 秒延至 300 秒；自动写作正文与两方向构思改为 SSE 流式，避免长思考触发网关超时；修复思考模型（如 `deepseek-flash`）写稿时输出 Token 被强截断导致推理耗尽返回空正文的问题，并在诊断中给出调高上限的明确指引；离线灵感对话输出上限提至 4096 Token。
- **自动写作中心修复**：点击章节卡片「对比审阅」时立即展开任务控制抽屉查看候选稿；运行日志时间改按本地时区显示。
- **窗口与任务管理器**：除书架页外，点击窗口右上角「×」关闭均增加防误触确认；Windows 安装版可执行文件写入 `墨笔生花` 描述与红印图标，任务管理器不再仅显示 `Electron`。

## 已知问题

- 拆书与云同步（仍标注「暂未开发」，暂未面向公开用户开放）未纳入本版真实模型回归范围。
- 小说移入回收站确认弹窗点击后会短暂等待持久化完成再关闭（待后续优化加载反馈）。
- 服务商、本机模型和各联网搜索路径（硅基流动、MiniMax、混元、OpenRouter、Ollama、LM Studio 等）尚未用真实密钥逐一实测。

## 安装

安装包为 `mobish-1.1.8.exe`，面向 Windows x64。1.0.10 及以后的版本可在软件内检查更新，也可手动下载安装；数据位置不变，更新前建议先备份项目。
