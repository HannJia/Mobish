# 墨笔生花 mobish 1.1.2

发布日期为 2026-11-22（北京时间）。本版重做知识库的导入、浏览和检索；墨笔生花从本版起以 MIT 许可证开源。

## 知识库

- **整份导入**：导入文件时默认“整份导入为一个条目”，一份资料不再被切成很多段，标题取文档的一级标题或文件名。也可以选“按标题拆分为多个条目”：按出现两次以上的最浅一级标题拆分，能识别“一、”“第一章”等中文标题，导入前可以预览每段的标题和字数。
- **拖拽导入**：可以把文件直接拖到知识库页面或导入窗口里。
- **支持网页文件**：新增 .html / .htm 导入，只读取正文，去掉脚本、样式和导航，不加载任何图片或外部链接；兼容 GBK 编码的网页。
- **上下排版**：上面是条目列表（每条一行：标题、类型、字数、摘要状态和操作，下面一行简短说明），列表自身可以滚动；点击条目后在下方显示完整内容，并带可折叠的目录，点击目录跳到对应位置。分类改为列表上方的筛选按钮，只显示实际用到的分类；知识库简介收进可展开的区域。阅读长资料时标题栏固定在顶部，可随时回到目录或条目列表。
- **按标题分段检索**：写作、规划和对话引用知识库时，软件把资料按标题切成小节，按关键词挑出最相关的几节原文交给 AI，并注明出处（如“《资料名》 › 二、完整时间线 › 阶段四”），同时附上资料的简短目录。不调用模型、不花费用；没有标题的资料按段落切成约一千字的小块。
- **Word、EPUB 保留标题层级**：Word 的“标题 1/2/3”样式、电子书的各级标题会按层级导入，便于拆分和检索。
- **AI 整理摘要暂时下线**：模型普遍不遵守摘要字数要求，长资料的分层摘要经常失败；按标题分段检索已能直接读到相关原文，所以隐藏了“整理摘要”。摘要栏保留为可选的手写简介，写了 AI 会一并参考。
- 正文中的引用（`>`）和行内代码会正常显示。

## 修复

- 模型的“高级参数”里可以填写“上下文窗口（选填）”，之前没有地方能填。
- 整理类请求使用 DeepSeek 官方接口时会关闭思考（实测 DeepSeek V4 默认会先思考，思考可能用光输出额度）；被截断时提示会写明思考用了多少 Token。

## 已知问题

以下问题已经记录，会在后续版本修复：

- **联网搜索**：
  - 默认的 Firecrawl 免费搜索在国内网络下通常无法访问；国内用户请在“设置 → 联网搜索”改用博查、智谱等服务，或使用通义、智谱、豆包等模型自带的搜索。
  - 浏览器版“测试搜索”在网络不通时可能一直显示“搜索中…”。
  - “联网搜索”设置页的几个输入框上下没有对齐。
- **灵感对话**：联网开关不在“背景信息窗口”旁边；“对话选项 · 历史与参考资料”不容易看出可以展开；“一句话灵感”下方的勾选框和说明文字分在两行；“继续已有讨论”按钮不够醒目。
- **知识库**：之前按旧规则被切成多段的条目不会自动合并，可以删除后重新“整份导入”；添加向量模型时“获取模型”会列出全部模型，请手动选择向量模型（如 `BAAI/bge-m3`）。
- 知识库正文中的 Markdown 表格暂时按原文显示（可以看到竖线 |），不影响 AI 读取。
- 除 Firecrawl 外，各厂商的联网搜索尚未用真实密钥逐一实测。
- 安装包尚未进行代码签名，Windows 可能显示未知发布者提示；发布页提供 SHA-256 校验文件。

## 安装

安装包为 `mobish-1.1.2.exe`，面向 Windows x64。1.0.10 及以后的版本可在软件内检查更新，也可手动下载安装；数据位置不变，更新前建议先备份项目。
